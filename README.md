# Опросы CUFA
Адаптация вёрстки, эмблемы и вариативного шрифта из [cufa_quiz](https://github.com/JamFloydzzz/cufa_quiz).
## Запуск
Требуется Node.js 22.13 или новее. Задайте пароль через переменную окружения ADMIN_PASSWORD и запустите npm start. Готовая сборка включена, установка пакетов не требуется. По умолчанию анкеты доступны на http://localhost:3000, кабинет на /admin. PORT задаёт порт, DB_PATH задаёт путь к файлу SQLite (по умолчанию cufa.sqlite). При переносе сохраните этот файл и настройте HTTPS перед сервером.
## Редактирование
После правок HTML, CSS, клиентского JS, seed.json или worker.mjs выполните npm run build (Python 3) и перезапустите сервер. Для Cloudflare Workers используйте dist/server/index.js с D1 binding DB. Таблицы создаются автоматически. В Sites настройте ADMIN_PASSWORD для замены начального пароля.
## Использование
Черновик хранится в браузере администратора. Каждая страница содержит один вопрос. Добавьте страницы, затем выберите переход для нужного варианта. После публикации структура фиксируется для сопоставимости ответов. В статистике процент считается среди ответивших на конкретный вопрос, при мультивыборе сумма может превышать 100%.
